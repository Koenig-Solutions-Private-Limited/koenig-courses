## What You Will Learn
- Deploy software discovery tools to build accurate inventory baselines and track usage metrics
- Analyze licensing models (perpetual, subscription, usage-based) for optimization and cost reduction
- Execute compliance audits using normalization standards like SWID tags and heartbeat data
- Develop governance policies for software request, deployment, and retirement lifecycles
- Mitigate risks through vendor management, contract negotiation, and blackout period enforcement
