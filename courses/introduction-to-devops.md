## What You Will Learn
- Core DevOps principles, including CALMS framework (Culture, Automation, Lean, Measurement, Sharing) for team alignment
- Version control mastery with Git, covering branching strategies, merges, and collaborative workflows
- Continuous Integration/Continuous Delivery (CI/CD) pipelines using tools like Jenkins for automated builds and testing
- Containerization fundamentals with Docker, including image creation, management, and multi-container apps via Docker Compose
- Introduction to Infrastructure as Code (IaC) with Terraform for provisioning cloud resources declaratively
