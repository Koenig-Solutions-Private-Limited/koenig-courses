## What You Will Learn
- Implement MPLS-based Layer 3 VPN architecture, including provider edge (PE) router configurations and label distribution
- Configure route distinguishers (RD) and route targets (RT) for VPNv4 route advertisement via MP-BGP
- Deploy PE-CE routing protocols such as OSPF, IS-IS, and BGP, with mutual redistribution in virtual routing instances
- Set up advanced features like carrier-of-carriers (CoC) VPNs and inter-AS option B connectivity
- Monitor and troubleshoot L3VPN issues using Junos tools like show route table vpn and MPLS traceroute
