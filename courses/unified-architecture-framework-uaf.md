# Unified Architecture Framework (UAF) — Training & Certification Guide

The [Unified Architecture Framework (UAF)](https://www.koenig-solutions.com/uaf-training?utm_source=github&utm_medium=backlink&utm_campaign=github-publisher) course delivers in-depth training on this ISO-standardized framework for enterprise architecture modeling. It covers the UAF Domain Metamodel, viewpoints across strategic, operational, and resource domains, and practical application in tools like Cameo Systems Modeler. Designed for architects and engineers in defense, government, and complex IT environments, UAF addresses the need for unified representations of systems, processes, and strategies amid digital transformation and interoperability demands.

Demand for Unified Architecture Framework (UAF) expertise surges in defense, aerospace, and enterprise IT, where standardized modeling ensures alignment between business goals and technical implementations. ## What You Will Learn
- Core elements of the UAF Domain Metamodel (DMM) for defining architecture elements and relationships
- Strategic architecture modeling, including actual enterprises, goals, and capability dependencies
- Operational architecture viewpoints for processes, services, and information exchanges
- Resource architecture for platforms, sensors, and software realizations with performance measures
- Cross-domain traceability, security overlays, and personnel modeling for holistic enterprise views

## Who Should Attend
