## What You Will Learn

- Configure authentication methods such as passwordless options, MFA, and self-service password reset (SSPR).

- Manage application access through enterprise apps, SAML/OIDC protocols, and API permissions.
- Execute identity governance tasks like entitlement management, access reviews, and lifecycle workflows.
