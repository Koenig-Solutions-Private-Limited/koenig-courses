## What You Will Learn
- MPLS packet forwarding and label imposition, swapping, and disposition mechanisms on Junos routers
- Configuration and verification of Label Distribution Protocol (LDP) for basic label-switched paths (LSPs)
- RSVP-TE signaling for traffic-engineered LSPs, including path computation and bandwidth reservation
- Implementation of Layer 3 VPNs using BGP and VRF tables for customer isolation
- Setup of Layer 2 VPNs via circuit cross-connect (CCC) and translational cross-connect (TCC) options
