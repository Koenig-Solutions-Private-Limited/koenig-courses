## What You Will Learn

- Develop extensions including application customizers, field formatters, and list view command sets
- Implement secure data access via SharePoint REST APIs, Microsoft Graph, and SPFx context properties
- Package solutions with bundlers, deploy to app catalogs, and provision via tenant-wide or site-specific scopes
