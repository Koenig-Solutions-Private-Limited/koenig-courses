## What You Will Learn
- Configure high-availability OpenStack control planes using Pacemaker, Corosync, and Galera clustering for fault-tolerant operations.
- Implement advanced Neutron networking with ML2 drivers, OVS/DPDK acceleration, and load balancer-as-a-service (LBaaS) for optimized traffic management.
- Integrate Ceph storage backends for resilient block (Cinder), object (Swift), and shared file systems (Manila) in large-scale deployments.
- Automate end-to-end deployments via TripleO or Kolla-Ansible, including overcloud provisioning and Day 2 operations.
- Tune performance with Ceilometer telemetry, Gnocchi metrics, and Aodh alarming for monitoring and autoscaling production clusters.

## Who Should Attend
