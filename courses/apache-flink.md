## What You Will Learn
- Flink's runtime architecture, including task managers, job managers, and distributed execution model
- DataStream and DataSet APIs for building low-latency stream and batch pipelines
- Stateful processing with keyed state backends like RocksDB and value state primitives
- Checkpointing, savepoints, and exactly-once semantics for production reliability
- Advanced windowing, event-time processing, and watermark strategies for temporal data
